# Atlas de Antibióticos — guía de estudio

Página de estudio de un solo archivo (`index.html`, sin dependencias de build) para repasar antibióticos antes de un examen tipo CACES/residencia: referencia por grupo farmacológico, casos clínicos con dosis, fichas de repaso y un quiz de opción múltiple.

## Publicar en GitHub Pages

1. Crea un repositorio nuevo en GitHub (puede ser público o privado; si es privado necesitas GitHub Pro para Pages).
2. Sube este `index.html` a la raíz del repositorio (arrástralo en la web de GitHub o usa `git add` / `git commit` / `git push`).
3. En el repositorio: **Settings → Pages**.
4. En "Source" selecciona **Deploy from a branch**, rama `main`, carpeta `/ (root)`, y guarda.
5. Espera 1–2 minutos: GitHub te dará la URL, algo como `https://tu-usuario.github.io/tu-repositorio/`.

No hace falta ningún paso de compilación: es HTML/CSS/JS puro en un solo archivo.

## Contenido

- **Referencia**: 16 grupos farmacológicos, 56 antibióticos con mecanismo, espectro y usos.
- **Casos clínicos**: 30 casos de examen organizados por especialidad, con dosis exactas.
- **Fichas**: modo de repaso tipo flashcard, barajable.
- **Quiz**: 35 preguntas de opción múltiple con retroalimentación inmediata.

Fuente: tus documentos Antibioticos_Resumen.pdf, Guia_Antibioticos.pdf y CACCES.pdf.
